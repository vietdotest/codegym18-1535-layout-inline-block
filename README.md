# Bố cục trang web với display

H1 theo đề, nav 4 liên kết, section 3 cột inline-block, footer. Dùng max-width, width và block; tính chiều rộng trừ margin để ba cột không rớt hàng.

## Chạy
Mở index.html trong trình duyệt.

## Đề bài
https://internship.codegym.vn/learning/18/activity/1535

## Kiểm tra
Đã mở ở 375, 768, 1440 px: không tràn ngang. Kiểm tra kích thước cột và float/display; các khung overflow có scrollHeight lớn hơn clientHeight khi nội dung dài.
